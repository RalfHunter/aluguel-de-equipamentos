# Plano de Teste para Model de Usuario (Sprint VIII)

| Funcionalidade                   | Comportamento Esperado                                                                 | Verificações                                                      | Critérios de Aceite                                                                                           |
|----------------------------------|----------------------------------------------------------------------------------------|-------------------------------------------------------------------|---------------------------------------------------------------------------------------------------------------|
| Cadastro válido de usuário       | Um usuário com todos os dados válidos deve ser salvo corretamente                      | Criar usuário com todos os campos preenchidos                    | O usuário é salvo e os dados (exceto senha) podem ser consultados com precisão                               |
| Email duplicado                  | O sistema não deve permitir dois usuários com o mesmo email                            | Tentar cadastrar dois usuários com o mesmo email                 | A operação falha com erro de chave duplicada referente ao campo `email`                                      |

| Isolamento entre testes          | Cada teste deve rodar com um banco limpo                                               | Verificar que limpeza é chamada após cada teste                  | Nenhum teste interfere no estado de outro, garantindo independência                                          |
